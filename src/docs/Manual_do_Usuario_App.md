# Manual do Usuário do App

## 1. Apresentação

Este manual foi criado para orientar o uso do aplicativo de forma prática, com foco no **fluxo real de trabalho**.

Mais do que explicar o que existe em cada tela, este documento mostra **como usar o sistema no dia a dia**, desde o primeiro contato com o cliente até o pós-venda e a análise dos resultados.

O objetivo do app é centralizar, em um único lugar:

- cadastro de clientes;
- criação de projetos e orçamentos;
- acompanhamento da jornada comercial;
- organização da agenda;
- registro financeiro;
- acompanhamento de revisão e pós-venda;
- leitura estratégica dos resultados.

---

## 2. O que o sistema resolve na prática

Na rotina, é comum que as informações fiquem espalhadas entre conversa no WhatsApp, agenda, anotações soltas, planilhas e memória.

O aplicativo foi pensado para resolver exatamente isso.

Com ele, você consegue:

1. registrar um novo cliente assim que o contato chega;
2. abrir um orçamento ou projeto com rapidez;
3. acompanhar em que etapa cada atendimento está;
4. saber quem precisa de retorno;
5. organizar sessões, revisões e pós-venda;
6. controlar valores recebidos;
7. enxergar os resultados do período com mais clareza.

---

## 3. Como pensar o uso do app

A melhor forma de usar o sistema é enxergar o processo em 3 blocos:

### 3.1 Bloco comercial
É a fase em que o cliente entra, recebe atendimento, orçamento e avança até o fechamento.

### 3.2 Bloco operacional
É a fase em que o projeto já foi fechado, a sessão é realizada e o acompanhamento continua com revisão e pós-venda.

### 3.3 Bloco financeiro e estratégico
É a fase em que os recebimentos são conferidos e os resultados são analisados para orientar decisões futuras.

Ou seja: o app não serve apenas para cadastrar dados. Ele serve para acompanhar o **ciclo inteiro do cliente**.

---

## 4. Fluxo recomendado de uso

A sequência ideal de uso no dia a dia é esta:

1. **Cadastrar o cliente** assim que o contato entrar.
2. **Criar o orçamento/projeto** com os dados do atendimento.
3. **Acompanhar a etapa no Pipeline**.
4. **Fazer os retornos necessários** com base na Home e nos follow-ups.
5. **Confirmar sinal e pagamento** quando o cliente avançar.
6. **Acompanhar a sessão na Agenda**.
7. **Registrar revisão e pós-venda**.
8. **Consultar o Financeiro** para acompanhar faturamento e lucro.
9. **Usar Análises** para interpretar os resultados e ajustar a operação.

Se esse fluxo for seguido com consistência, o sistema passa a funcionar como um painel confiável da operação.

---

## 5. Primeiros passos antes de começar

Antes de usar o app no dia a dia, vale conferir alguns pontos iniciais.

### 5.1 Ajustar configurações
Na tela **Configurações**, revise:

- percentuais de comissão por forma de pagamento;
- nomes das formas de pagamento;
- meta mensal de lucro.

Isso é importante porque a Home, o Financeiro e as Análises usam essas informações nos cálculos.

### 5.2 Definir padrão de preenchimento
Para manter o sistema organizado, adote um padrão interno para:

- descrição do projeto;
- preenchimento de observações;
- uso correto das etapas do pipeline;
- registro das datas principais.

### 5.3 Manter disciplina de atualização
O sistema funciona melhor quando as informações são atualizadas no momento em que as coisas acontecem.

Exemplo:
- chegou cliente novo -> cadastrar;
- virou orçamento -> criar projeto;
- fechou -> atualizar etapa;
- recebeu sinal -> confirmar;
- realizou sessão -> manter datas corretas;
- precisou retorno -> acompanhar pela Home.

---

## 6. Rotina diária recomendada

Uma forma prática de usar o app todos os dias é seguir esta ordem:

### 6.1 Comece pela Home
Ao abrir o sistema, use a Home para responder rapidamente:

- o que precisa de atenção hoje?
- quem precisa de retorno?
- como está o resultado do período?
- existem tarefas atrasadas ou pendentes?

### 6.2 Verifique tarefas e follow-ups
Na Home, observe:

- tarefas pendentes;
- follow-up de orçamento;
- follow-up de vendas;
- revisão e pós-venda.

Esses blocos mostram quem precisa de ação imediata.

### 6.3 Consulte a Agenda
Depois, confira a Agenda para entender:

- quais compromissos existem no dia;
- quais clientes serão atendidos;
- se há revisão ou pós-venda previsto;
- se existe algum ajuste a fazer na organização da semana.

### 6.4 Atualize conforme os atendimentos acontecem
Durante o dia:

- cadastre novos clientes;
- crie novos projetos;
- atualize etapas no pipeline;
- confirme pagamentos;
- registre observações importantes.

### 6.5 Feche o dia com uma revisão rápida
No final do dia, vale conferir:

- se os clientes atendidos foram atualizados;
- se os pagamentos foram registrados;
- se a agenda futura está coerente;
- se alguém ficou sem retorno.

---

## 7. Rotina semanal e mensal

Além da rotina diária, o sistema também ajuda em revisões mais amplas.

### 7.1 Revisão semanal
Uma vez por semana, recomenda-se:

- revisar o Pipeline por completo;
- identificar clientes parados há muito tempo em uma etapa;
- verificar se há revisões e pós-vendas próximos;
- acompanhar a evolução do faturamento e do lucro.

### 7.2 Revisão mensal
No fechamento do mês, recomenda-se:

- conferir faturamento total;
- conferir lucro/comissão;
- comparar com a meta mensal;
- analisar quais estilos performaram melhor;
- revisar ranking de clientes e origem de leads;
- identificar gargalos comerciais.

---

## 8. Passo a passo do fluxo completo de atendimento

## 8.1 Etapa 1 - Entrada de um novo contato

Quando surgir um novo interessado, o primeiro passo é decidir se ele já existe na base.

### Se o cliente ainda não existir:
1. entre em **Novo Cliente**;
2. preencha nome e WhatsApp;
3. complete os demais dados quando houver;
4. salve o cadastro.

### Se o cliente já existir:
1. localize na tela **Clientes**;
2. abra os detalhes do cliente;
3. siga para criação de um novo projeto/orçamento.

### Boas práticas nessa etapa
- cadastre o cliente o quanto antes;
- não deixe contatos apenas no WhatsApp;
- use corretamente a origem do lead;
- mantenha o telefone padronizado.

---

## 8.2 Etapa 2 - Criação do orçamento ou projeto

Depois do cadastro, o próximo passo é abrir o projeto.

Na tela **Novo Orçamento / Novo Projeto**, você registra:

- cliente vinculado;
- descrição do trabalho;
- estilo;
- valor total;
- valor do sinal;
- data prevista;
- duração;
- forma de pagamento;
- observações relevantes.

### Quando criar o projeto
O ideal é criar o projeto assim que a negociação estiver concreta o suficiente para acompanhamento.

### Por que isso é importante
É a partir do projeto que o sistema consegue:

- exibir o cliente no pipeline;
- alimentar agenda;
- organizar histórico;
- apoiar follow-ups;
- alimentar o financeiro e as análises depois.

---

## 8.3 Etapa 3 - Acompanhamento no Pipeline

Depois que o projeto existe, ele passa a ser acompanhado no **Pipeline**.

O Pipeline é o coração do acompanhamento comercial.

Ele responde perguntas como:

- em que etapa cada cliente está?
- o que está parado?
- o que avançou?
- o que precisa de retorno?

### Como usar no dia a dia
Sempre que o cliente evoluir, a etapa deve ser atualizada.

Exemplo de leitura prática:

- **novo contato** -> cliente entrou e ainda está em fase inicial;
- **agendado orçamento presencial** -> existe encontro marcado para avaliação;
- **follow-up de fechamento** -> precisa retomar após orçamento;
- **aguardando sinal** -> o cliente quer avançar, mas ainda falta confirmar o sinal;
- **agendado** -> sessão confirmada;
- **revisão** -> fase de acompanhamento após a sessão;
- **pós-venda** -> etapa final de relacionamento;
- **perdido** -> negociação encerrada sem avanço.

### O que fazer em cada etapa

#### Novo contato
- entender demanda do cliente;
- registrar projeto inicial;
- conduzir para orçamento presencial ou remoto.

#### Agendado orçamento presencial
- garantir que a data esteja correta;
- acompanhar comparecimento;
- atualizar etapa depois do atendimento.

#### Follow-up de fechamento
- retomar o contato;
- verificar objeções;
- tentar converter em fechamento.

#### Aguardando sinal
- reforçar prazo e próxima ação;
- acompanhar até confirmar o recebimento.

#### Agendado
- manter sessão organizada;
- revisar informações do projeto;
- garantir consistência da agenda.

#### Revisão
- acompanhar o momento adequado para retorno;
- verificar necessidade de ajuste.

#### Pós-venda
- manter relacionamento ativo;
- reforçar experiência;
- abrir espaço para nova venda ou indicação.

---

## 8.4 Etapa 4 - Uso da Home como central de execução

Depois que o fluxo está em andamento, a Home passa a ser a tela principal de trabalho.

Ela não é apenas um painel bonito. Ela é uma central de priorização.

### O que deve ser observado primeiro
Ao abrir a Home, priorize esta ordem:

1. tarefas pendentes;
2. clientes em follow-up;
3. revisão e pós-venda;
4. indicadores do período.

### Como interpretar os blocos

#### Tarefas
Mostram pendências objetivas que precisam de ação.

#### Follow-up Orçamento
Mostra quem precisa ser retomado após orçamento ou ausência.

#### Follow-up Vendas
Mostra quem está perto de fechar ou aguardando sinal.

#### Revisão e Pós-Venda
Ajuda a manter a continuidade do relacionamento depois da sessão.

### Objetivo prático da Home
A Home deve ajudar você a decidir:

- quem chamar agora;
- qual projeto está travado;
- qual valor já entrou no período;
- quanto falta para a meta.

---

## 8.5 Etapa 5 - Agenda e execução operacional

A tela **Agenda** deve ser usada para acompanhar compromissos futuros e a ocupação da rotina.

Ela é especialmente útil para:

- visualizar sessões marcadas;
- acompanhar revisões;
- acompanhar contatos de pós-venda;
- entender a distribuição dos compromissos na semana ou no mês.

### Uso prático
Antes de começar a semana:
- confira a visão semanal ou mensal;
- identifique dias mais cheios;
- verifique revisões próximas;
- confirme se os projetos certos aparecem nas datas corretas.

No dia do atendimento:
- abra os detalhes do projeto a partir da agenda, se necessário;
- confira descrição, valores e observações;
- atualize o projeto caso algo mude.

---

## 8.6 Etapa 6 - Registro de pagamento

O sistema também ajuda a organizar o acompanhamento financeiro.

Sempre que houver recebimento, o ideal é registrar isso no contexto correto do projeto.

### Por que isso importa
Se o recebimento não for confirmado corretamente:

- a Home pode mostrar números distorcidos;
- o Financeiro pode ficar incompleto;
- as Análises podem refletir uma leitura errada do período.

### Boas práticas
- confirme o sinal quando ele realmente for recebido;
- confirme o valor total quando o pagamento acontecer;
- use a forma de pagamento correta;
- não deixe para registrar tudo depois, pois isso aumenta erro.

---

## 8.7 Etapa 7 - Revisão e pós-venda

Depois da sessão, o relacionamento não termina.

O sistema ajuda a acompanhar:

- retorno para revisão;
- necessidade de retoque;
- contato de pós-venda.

### Por que essa etapa é importante
Ela melhora:

- experiência do cliente;
- chance de recorrência;
- chance de indicação;
- percepção de cuidado e organização.

### Como operar
- acompanhe a fase de revisão;
- use a Home para ver quem precisa de retorno;
- registre observações relevantes;
- mantenha o pós-venda ativo quando fizer sentido.

---

## 8.8 Etapa 8 - Leitura de resultado

Depois de alimentar corretamente o sistema, entram em cena duas telas estratégicas: **Financeiro** e **Análises**.

### Financeiro
Use quando quiser entender:

- quanto entrou no período;
- qual foi o lucro/comissão;
- como os recebimentos se dividiram por forma de pagamento;
- quais foram os lançamentos mais recentes.

### Análises
Use quando quiser responder:

- como está a conversão;
- qual o ticket médio;
- quais estilos geram mais resultado;
- quais clientes têm maior valor;
- quais pontos merecem atenção;
- quais decisões podem melhorar o próximo período.

## 10. Cenários práticos de uso

## 10.1 Chegou um novo cliente pelo Instagram
1. cadastre em **Novo Cliente**;
2. informe a origem do lead;
3. crie o projeto;
4. acompanhe no Pipeline.

## 10.2 O cliente fez orçamento, mas não respondeu mais
1. localize no Pipeline;
2. mantenha na etapa correta de follow-up;
3. acompanhe os retornos pela Home;
4. registre a evolução quando houver resposta.

## 10.3 O cliente confirmou e pagou o sinal
1. abra o projeto;
2. confirme as informações financeiras;
3. atualize a etapa para a fase correta;
4. garanta que a agenda reflita o atendimento.

## 10.4 Quer saber como o mês está indo
1. abra a Home para visão rápida;
2. abra o Financeiro para conferência dos números;
3. abra Análises para interpretação e próximos passos.

## 10.5 Precisa saber quem está parado
1. abra o Pipeline;
2. identifique etapas com clientes travados;
3. use a Home para priorizar o contato;
4. avance ou encerre os casos conforme a realidade.

## 11. Regras de preenchimento que ajudam muito

Para o sistema entregar valor real, alguns cuidados fazem diferença.

### 11.1 Cadastre o cliente antes de confiar na memória
Se o contato existe, ele deve estar no sistema.

### 11.2 Crie o projeto com descrição clara
Evite descrições vagas demais.

### 11.3 Atualize a etapa no momento certo
Etapa desatualizada gera leitura errada do pipeline.

### 11.4 Confirme pagamentos corretamente
Os resultados dependem disso.

### 11.5 Use observações com critério
Registre o que realmente ajuda no acompanhamento futuro.

### 11.6 Revise a agenda com frequência
Isso evita esquecimentos e conflitos.

---

## 12. Erros mais comuns de operação

### 12.1 Deixar cliente só no WhatsApp
Isso enfraquece o histórico e dificulta o acompanhamento.

### 12.2 Criar projeto sem atualizar depois
O cadastro inicial sozinho não resolve se a etapa ficar parada no sistema.

### 12.3 Confirmar pagamento tarde demais
Isso distorce os números do período.

### 12.4 Não usar a Home como painel de prioridade
Nesse caso, o usuário perde a principal vantagem operacional do app.

### 12.5 Não revisar o Pipeline
Sem revisão frequente, clientes parados ficam escondidos.

---

## 13. Boas práticas de uso

- abra a Home todos os dias;
- revise o Pipeline com frequência;
- use a Agenda para antecipar a semana;
- mantenha pagamentos em dia no sistema;
- não acumule atualização para depois;
- registre follow-ups de forma consistente;
- use Análises para orientar decisões, e não apenas para consultar curiosidade.

---

## 14. Resumo rápido do fluxo ideal

Se quiser resumir o uso do sistema em uma frase, ela seria:

**cliente entra -> cliente é cadastrado -> projeto é criado -> etapa é acompanhada -> pagamento é confirmado -> agenda é acompanhada -> pós-venda é executado -> resultado é analisado.**

Esse é o fluxo central do aplicativo.
